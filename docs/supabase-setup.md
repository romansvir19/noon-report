# Облако для Noon Report: настройка Supabase (один раз, ~15 минут)

## 1. Проект

1. Зайти на [supabase.com](https://supabase.com) → Sign up (можно через GitHub).
2. New project: имя `noon-report`, регион — ближе к тому, где чаще бываешь
   (Frankfurt для Европы, Singapore для Азии). Пароль базы — записать, он больше нигде не нужен.
3. Дождаться, пока проект поднимется (1–2 минуты).

## 2. Таблицы

1. Слева **SQL Editor** → New query.
2. Вставить целиком содержимое файла `supabase/schema.sql` из репозитория → **Run**.
   Должно быть «Success. No rows returned».

## 3. Аккаунт

1. Слева **Authentication → Users → Add user → Create new user**.
   E-mail и пароль — те, что будешь вводить на телефоне и ПК. Поставить галочку
   **Auto Confirm User**.
2. **Authentication → Sign In / Providers → Email**: выключить **Allow new users to sign up**.
   Теперь чужой не сможет завести себе учётку.

## 4. Ключи для приложения

**Project Settings → API**:

- **Project URL** — вида `https://abcdefgh.supabase.co`
- **anon public** ключ (длинная строка). Он публичный по замыслу: сам по себе
  доступа к данным не даёт, доступ режется правилами RLS из `schema.sql`.

Эти два значения вписаны в `index.html` (константы `SB_URL`, `SB_KEY`).
При смене проекта — заменить их и поднять версию в `sw.js`.

## 5. Защита от «засыпания» (бесплатный тариф)

Проект без запросов неделю ставится на паузу. В репозитории есть
`.github/workflows/keepalive.yml`, который раз в сутки делает один запрос;
адрес и ключ в нём уже прописаны, настраивать ничего не нужно. Проверить,
что он работает: GitHub → вкладка **Actions** → keepalive → Run workflow.

Если проект всё же уснул: Supabase → проект → кнопка **Restore**. Данные не теряются.

## 6. Порядок включения на устройствах

1. **Судовой ПК** (там полная история): открыть приложение → ☁ в шапке → войти →
   «Отправить мои данные в облако».
2. **Телефон**: открыть приложение → ☁ → войти → «Заменить мои данные облаком».
3. Дальше всё само: при любой связи устройства обмениваются изменениями.
   Пилюля ☁ в шапке показывает время последнего обмена или сколько записей ждут отправки.

Напоминания, черновик и ночной режим в облако не ходят — они на каждом устройстве свои.
