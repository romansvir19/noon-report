# Noon Report

Офлайн-приложение (PWA) для судового полуденного отчёта. Работает без интернета,
все данные хранятся на самом устройстве.

## Что внутри

| Файл | Что это |
|---|---|
| `index.html` | всё приложение: разметка, стили, расчёты |
| `sw.js` | офлайн-кэш (service worker) |
| `manifest.json` | описание приложения для установки на телефон/ПК |
| `icon-*.png`, `apple-touch-icon.png` | иконки |
| `deploy/` | те же файлы, готовые к выгрузке на хостинг |

## Как выложить обновление

1. Перетащить папку `deploy` на [app.netlify.com](https://app.netlify.com) (Deploys → drag & drop).
2. На судовом ПК открыть сайт при наличии интернета — обновление подтянется само.

⚠️ Перетаскивать нужно именно `deploy`, а не всю папку проекта.

## Важно при правках кода

После любого изменения `index.html` нужно:

1. поднять номер версии в `sw.js` (строка `const V = 'noon-report-vNN'`) —
   иначе на устройствах останется старая версия из кэша;
2. скопировать файлы в `deploy/`:

```bash
cp index.html manifest.json sw.js icon-192.png icon-512.png apple-touch-icon.png deploy/
```

## Возможности

- репорты по переходам: начало перехода → ежедневные репорты → завершение;
- несколько репортов за сутки (NOON, EOSP, COSP, Departure, Arrival, Anchor);
- длительность периода считается от времени прошлого репорта, с учётом перевода часов;
- дистанции GPS и лага, скорости, течение, погода, ME и дизель-генераторы;
- Deck Log Book с накоплениями по переходу; любое поле можно переписать вручную,
  и дальше счёт идёт от своей цифры;
- напоминания: постоянные по дням недели (карты — Чт, GMDSS — Сб) и разовые заметки;
- ночной режим, экспорт и импорт резервной копии в JSON.

## Резервная копия данных

Сами репорты в этот репозиторий не попадают — они лежат в браузере устройства.
Раз в неделю-две стоит нажимать «Экспорт» в приложении и сохранять JSON-файл.

## Как обновить резервную копию

Двойной клик по файлу `backup.command` в папке проекта — он сам отправит
изменения на GitHub.
